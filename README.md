# Aoe3DE-noIntroCinematics-Toolkit
Simple tools to fix glitches when using the '+noIntroCinematics' string in Age of Empires 3: Definitive Edition.

You can skip the cinematic intros in AoE3:DE by adding the string "_+noIntroCinematics_" to the game's launch options in Steam.

However, after making this change, the game might launch in a _different X/Y position_ that is misaligned with your display, even though it starts up faster.

To fix this, simply change the resolution to something else and then switch back to your original setting; the glitch will disappear.

To save you the trouble of opening Windows settings every time this happens, I created simple executables that handle this process.
