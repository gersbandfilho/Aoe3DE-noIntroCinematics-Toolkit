RESOLUTION SWITCHER (For 1920x1080p)

This project changes the primary Windows display to:
1600x900
Then waits 1 second and turns back to:
1920x1080

HOW TO BUILD
1. Install .NET 8 SDK for Windows (x64).
2. Open this folder.
3. Double-click build.bat.
4. The finished executable will be at:
   publish\ResolutionSwitcher.exe

The resulting EXE is self-contained and does not require QRes or similar apps.
